Hamburger Menu Examples

Coding exercise exploring ways to build a hamburger menu

What is a hamburger menu?

A hamburger menu is a navigation pattern that hides a website’s menu links behind a ☰ icon. The icon usually looks like three horizontal lines, which is why it is called a hamburger menu.

When the user clicks or taps the icon, the hidden navigation menu appears. This pattern is very common on phones and tablets because smaller screens do not have as much room for a full horizontal navigation bar.

Why do websites use hamburger menus?

Hamburger menus help save space and keep layouts cleaner, especially on mobile devices. Instead of showing every navigation link all the time, the menu can stay hidden until the user needs it.

This can be helpful, but it also creates a tradeoff. If navigation is hidden, users have to notice the icon and interact with it before they can see where to go next.

Advantages

  • Saves space on small screens
  • Can make a layout feel cleaner
  • Works well for mobile-first navigation
  • Helps organize navigation in a compact way

Disadvantages

  • Navigation is hidden until clicked
  • Some users may not notice the icon right away
  • Important links can become less visible
  • It can hurt usability if overused or poorly designed

Tips for this learning exercise

  • Pay attention to how the HTML is structured.
  • Notice how CSS is used to hide and reveal the menu.
  • Compare the basic version to the animated versions.
  • Think about how the menu would behave on a phone versus a desktop computer.
  • Remember that a feature is only useful if it helps the visitor navigate the site more easily.

Keep in mind

A hamburger menu is not always the best choice. Designers use them when space is limited, but hiding navigation can sometimes make a site less clear. As you explore these examples, think not just about how the code works, but also about when this kind of navigation is a good idea.
